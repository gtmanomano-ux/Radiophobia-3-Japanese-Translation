# packets からゲームへの適用方法

## 対象

`packets` の9ジャンルにあるJSONは翻訳作業用のデータです。ゲームはJSONを直接読みません。適用スクリプトが各項目の `JA_new` を、`F:\Games\Radiophobia 3\gamedata\config\text\jpn\` 内の対応するXMLへ書き込みます。対応先は各項目の `source_table`、`string_id`、`occurrence` で特定します。`EN` と `JA_current` は参照・照合用です。

## 初回適用の手順

この手順は、`manifest.json` の `jpn_sha256` とゲーム内の元XMLが一致する状態でのみ使えます。ゲームを終了してから、PowerShellで実行してください。

```powershell
Set-Location -LiteralPath 'F:\Games\Radiophobia 3\Translate'
python '.\scripts\_apply_packets_to_game.py' diagnose
python '.\scripts\_apply_packets_to_game.py' check
python '.\scripts\_apply_packets_to_game.py' apply
```

- `diagnose` は元XMLとパケットの `JA_current` を照合します。
- `check` は書き込み前に全パケット、XML構造、文字列ID、元ファイルのハッシュを確認し、変更予定数を表示します。
- `apply` は変更対象XMLを `Translate\backups\packet_apply_日時\` に退避してから書き込みます。表示された `backup=` の場所を控えてください。

適用後の照合には、`apply` が表示したバックアップフォルダを指定します。

```powershell
python '.\scripts\_apply_packets_to_game.py' verify --backup 'F:\Games\Radiophobia 3\Translate\backups\packet_apply_日時'
```

`verify` が `live_xml_differences=0` を表示すれば、対象XMLはパケットの適用結果と一致しています。最後にゲームの言語設定 `g_language jpn` で起動すると、適用したテキストが使われます。

## 現在の導入状態と再適用時の注意

この環境では、パケットの翻訳は既にゲームへ適用済みです。初回適用時のバックアップは `Translate\backups\packet_apply_20260927_233410\` です。その後、字幕とフォントにも別の変更が加えられています。

`_apply_packets_to_game.py` の `diagnose`・`check`・`apply` は、**パケット作成時の元XMLとゲーム内XMLのハッシュが一致すること**を要求します。適用済みの現在のゲームにそのまま再実行すると、元ファイルのハッシュ不一致で停止します。`JA_new` を編集しただけではゲームへ自動反映されません。また、字幕導入後は `stable_game_credits.xml` も変わっているため、初回バックアップを指定した `verify` もそのままでは全件一致しません。

今後パケットを修正して再適用する場合は、現在のXMLと字幕を保持したまま差分だけを書き込む手順またはスクリプトを別途用意してください。初回用スクリプトに合わせてゲーム内XMLを古いバックアップで一括上書きすると、その後の字幕などの変更が失われます。

## 対象外の翻訳

字幕はこの `packets` の適用対象ではありません。字幕用データは `Translate\subtitles\stable_closecaption.json`、適用スクリプトは `Translate\scripts\_apply_subtitles.py` です。新しい漢字などがフォントにない場合は、XMLだけを更新しても正しく表示できません。フォントの追加処理は `Translate\scripts\_extend_japanese_font.py` が担当します。
